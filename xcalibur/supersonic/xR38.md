# xR38

## K2: xR38F1

`xR38F1_bf16` in [xR38F1.cu](xR38F1.cu).

- Grid = `(E,1,1)`; block = `(768,1,1)` = 24 warps; target = 2 CTA / SM.
- 1 CTA = 1 expert; 1 warp = I8 × token8; I step = 192.
- smem = 32 KiB; `rmem[28]`, all slots used. Physical registers and spills: [compiler report](../../tests/README.md).

### Phase 1: Route lookup & Gather

`xR38F1Route` scans K1's N×K routes/expert. Publish in token order; gather eight accepted tokens. `ld.cg.v4` → `st.v4`. Reuse one Xs batch/expert; zero-fill final tail.

CTA barriers after route publication and after each route iteration protect header reads, gather and batch reuse.

### Phase 2: Gate@Xs, Up@Xs

`xR38F1Compute_bf16`: W13 packed at checkpoint creation. All warps reduce full H; shared X reused across 24 warps.

- **Compute entry:** CTA barrier publishes gathered Xs and the route header to readers.
- **Stage H1536:** 2 × 16B `ld.global.cs` → `st.shared`/thread → CTA barrier. Xs loads request evict-first in L1 and L2; invalid vectors write zeros.
- **Per H64:** 4 × `ld.global.nc.L2::256B.v4` W13/lane with L2 evict-last; 2 × `ldmatrix.x4`; 4 × `mma.sp.m16n8k32`.
- **Stage consumed:** CTA barrier before shared X reuse across H stages or I tiles.

Gate/Up occupy different rows of one FP32 fragment. Complementary masks reconstruct dense products.

### Phase 3: SwiGLU, topkW, write out

`xR38F1Epilogue_bf16`:

- After full H: pack Gate/Up into BF16 pairs; BF16 rounding after each epilogue operation. MMA accumulation stays FP32.
- `e = exp(-abs(Gate))`; `s = 1/(1+e)`; negative Gate uses `e*s`. Then `Gate*s*Up*topkW`. Exp/reciprocal use FP32 approximate SFUs and round back to BF16; add/multiply use packed BF16 FMA.
- XOR-4 pairs adjacent I rows. Fixed expert slabs; Y uses Xs packing along I.

### E. Y → K3

```text
Y: | expert 0 slab | expert 1 slab | ... |

expert slab
+------------------------+------------------------+-----+
| count + 7 zero words   | batch 0                | ... |
+------------------------+------------------------+-----+

batch record
+-------------+-----------------------------------+
| 8 token IDs | payload: ceil(I/8) × token8 × 4   |
+-------------+-----------------------------------+

Ib = ceil(I/8); B = ceil(N/8)
S = 8+32*Ib; D = 8+B*S; allocate E*D words
record  = Y + e*D + 8 + batch*S
payload = record + 8
count = valid batches; padding = 7 zero words
```

Payload uses appendix C's memory map with I replacing H. Tail IDs = `0xffffffff`; padded values = 0. Read only `count` batches. Fixed capacity reserves N rounded to eight slots/expert; token IDs drive K3 scatter.

### F. PTX helper contracts

- `swiglu_topkw_bf16x2(x,y,w)`: packed Gate, Up and routing-weight pairs; low/high halves are adjacent tokens. Rounds every intermediate to BF16.
- `cvt_bf16x2_f32(x,y)`: low = x; high = y; rounds Gate/Up before activation.
- `mul_bf16x2(x,y)`: packed BF16 multiply via `fma.rn.bf16x2` with negative zero; `add_bf16x2` uses BF16 FMA with one on SM80+.
- `ldcg_b16x8(src,dst,size)`: size = 0..8 valid BF16 elements; zero-fill the remainder.
- `ldnc_evict_last_b32v4(src,dst)`: W13-only non-coherent load; L2 evict-last policy at fraction 1.0, 256B prefetch hint. SM80+.
- `cp_smem_cs_b32v4(src,dst,valid)`: coherent streaming load into shared memory; L1/L2 evict-first. Copies 16B or writes 16B of zeros. Uses registers because SM89 `cp.async` does not expose L1 evict-first.
